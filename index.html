Introduction

notification project is Spring Boot, Gradle based project and can be used for reference purpose. This project will help when you are developing new project and wants to implement spring boot features. You can download this project and refer how different features are implemented to save time.

Features

Below are the features present in notification project for your reference:

  • spring boot
  • REST API
  • Web application
  • logging cofiguration (usage of logger)
  • security for authentication
  • Spring Actuator
  • error page configuration.
